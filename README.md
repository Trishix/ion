# Ion

Ion is a planned local coding-agent harness for the AI Harness Hackathon 2026 and a continuing developer product.

**Status: architecture and product documentation only.** The coding engine, Makefile, TUI, integrations, and runtime tests have not been implemented.

Start with the [product documentation](docs/README.md). The [hackathon requirements](docs/rules.md) distinguish organizer mandates from design policies, and track official details that still need confirmation.

The proposed v1 is TUI-only: it uses Python, a local durable task engine, a prescribed text-only model, and source-linked repository memory. All user-facing task workflows run in the TUI. See [the architecture](docs/architecture.md) and [the implementation plan](docs/implementation-plan.md).
